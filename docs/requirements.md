# 需求与范围

依据用户本次要求及其提供的 `ERP_MCP开发流程与工具标准.md`，将 OA 总结作为工程参考，U9 的认证、路径、状态和业务数据以官方文档及本机实测为准。

| 项目 | 本次确定内容 |
| --- | --- |
| 首个业务问题 | 在授权组织中按准确料号查询一个料品档案 |
| 选择依据 | 用户要求“先实现功能”，采用已说明的单料品只读场景 |
| 环境版本 | 登录及“关于”页确认 U9Cloud 标准版；完整版本号和补丁清单仍待提供 |
| API 文档 | 官方 OpenAPI JSON 与 17 页接入说明，详细来源见接口映射 |
| 认证 | 用户确认 clientid/clientsecret 等参数含义；AuthLogin 在本机成功 |
| 企业和组织 | 用户提供并确认，在 ERP 登录页与接口响应核实；实际值仅存私有配置和核对文件 |
| 权限 | 服务进程固定 ERP 身份；输入组织校验、ERP Token 身份及返回组织核对共同约束；远程入口另用 Bearer 令牌保护 |
| 输出 | 编码、名称、规格、组织和库存/采购/销售单位，ID 使用字符串 |
| 排除 | 写入、库存数量、状态解释、财务金额、跨组织、统计、模糊搜索、聊天界面、多用户身份和 OAuth |

业务规则：名称不作为唯一键；空值与缺失字段区分；零结果是成功查询；接口异常不视为空结果；多条返回不擅选第一条；首尾空白和额外字段不静默修正；金额/数量不依赖大模型计算。

本阶段的“完整接口文档”交付为全量接口和 Model 原文结构索引及全节点检查。逐工具业务核对只覆盖首个已实现工具，不代表 618 个操作均在授权环境执行或完成所有业务口径确认。
